# Support

## Before opening an issue

1. Confirm you are running the latest release.
2. Press **Refresh** and note the provider/source label and last update time.
3. For Claude Web, keep one signed-in `claude.ai` tab open in the same Chrome profile as Pulse Connector.
4. Search existing issues.

## Bug report checklist

Include:

- Codex Pulse version and build;
- macOS version and Mac architecture;
- affected surface: dashboard, menu bar, widget, settings or connector;
- exact steps and expected/actual behavior;
- a screenshot with account emails, client names and private project data removed;
- whether Codex, Claude Web or both are affected.

Never post cookies, access tokens, pairing tokens, raw authenticated responses, prompts or chat contents.

Questions and release notes are also shared in [Roman Sharafutdinov’s Telegram channel](https://t.me/shromarketing). Please keep reproducible bugs on GitHub so other users can find the solution.
