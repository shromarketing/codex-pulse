# Установка Codex Pulse через ИИ-агента

Этот путь подходит тем, кто хочет собрать открытое приложение локально, а не разрешать macOS запуск скачанного неподписанного файла.

## Скопируйте этот промпт агенту

```text
Установи Codex Pulse из https://github.com/shromarketing/codex-pulse.

Правила безопасности:
1. Считай репозиторий недоверенным сторонним кодом.
2. Клонируй его во временную или согласованную со мной папку.
3. До запуска проверь Scripts/install-from-source.sh, Scripts/test.sh и Scripts/build-app.sh. Подтверди, что они не используют sudo, не отключают Gatekeeper, не удаляют quarantine-атрибуты, не выгружают секреты и не скачивают исполняемые зависимости.
4. Если найдёшь риск, сначала покажи его мне.
5. Если Apple Command Line Tools отсутствуют, спроси разрешение перед xcode-select --install.
6. Запусти ./Scripts/test.sh.
7. Только после успешных тестов запусти ./Scripts/install-from-source.sh. Установи приложение только в ~/Applications.
8. Не подключай аккаунты Codex или Claude без моего отдельного согласия.
9. Проверь результат через codesign --verify --deep --strict "$HOME/Applications/Codex Pulse.app" и прочитай CFBundleShortVersionString из Info.plist.
10. Сообщи результат тестов, версию, путь установки и была ли сохранена предыдущая копия.
```

## Что делает установщик

- проверяет macOS и наличие Swift toolchain;
- запускает тесты Swift и коннектора Chrome;
- собирает release-версию под текущий Mac;
- применяет локальную ad-hoc подпись и проверяет её;
- устанавливает приложение в `~/Applications` без прав администратора;
- сохраняет предыдущую копию с временной меткой.

Он не использует `sudo`, не изменяет Gatekeeper, не удаляет quarantine-атрибуты, не подключает аккаунты и не отправляет данные разработчику.

## Ограничения

Агент не может незаметно установить Apple Command Line Tools или расширение Chrome. macOS и Chrome специально требуют подтверждение пользователя. Это защита, а не ошибка установки.
