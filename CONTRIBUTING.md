# Contributing

Codex Pulse is preparing for a public beta. Contributions should preserve these invariants:

- read-only provider access;
- no prompt or chat collection;
- no hidden telemetry;
- explicit source confidence and disconnected states;
- Russian and English copy for every user-facing string;
- macOS 13+ compatibility unless a release decision changes it.

Run `swift build` and complete visual QA before proposing UI changes.
