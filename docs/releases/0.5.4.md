# Codex Pulse 0.5.4 — Public Preview

Обновление нативного приложения для macOS 13+; universal-пакет подходит для Apple Silicon и Intel.

## Что обновилось

- В строке меню Claude показывает текущую сессию первой, общую неделю второй; метки окон отделены от процентов остатка.
- Исправлен поиск Codex CLI после переноса в ChatGPT.app, улучшены русские и английские сообщения об отсутствующем CLI.
- Сигналы Tibo находят оригинальный пост через резервные публичные индексы при устаревших/test данных основной ленты. Анонсы по дню недели распознаются без выдуманного точного часа.
- Добавлен отдельный экспериментальный Claude OAuth-источник по явному согласию, обработка 401/429, выбор доступного источника и отображение времени устаревших измерений.
- Повторное чтение старого снимка Claude больше не создаёт новые точки расхода; прошедшие окна лимита скрываются до нового измерения.

## Установка

Скачайте `CodexPulse-0.5.4-macos-universal.dmg` либо ZIP приложения и сверьте его SHA-256 с `SHA256SUMS`. ZIP `CodexPulse-Connector-0.5.4.zip` содержит отдельное расширение Chrome, а не приложение.

## Важные ограничения

- Это **preview**: приложение ad-hoc подписано, но без Apple Developer ID и нотарификации. macOS не может подтвердить издателя; не отключайте системную защиту ради установки.
- Claude OAuth — опциональный эксперимент, не одобренный Anthropic публичный API квот. Он может получать HTTP 429. Не включайте доступ к Keychain, если не принимаете этот способ подключения.
- Pulse Connector требует открытой авторизованной вкладки Claude Web. Локальная история Claude Desktop может отставать; гарантированного получения свежих лимитов только из десктопа пока нет.
- Мод Claude Code с индикатором контекста и переходом в новый диалог **не входит** в этот релиз.
- Полная живая перепроверка нового build на всех UI-поверхностях, языках и темах, а также подключения Claude на новом аккаунте остаётся открытой. Preview не является подтверждением полной совместимости.

## Проверка

- Локально: 62 Swift-теста в 11 наборах, browser popup/parser checks, release native build.
- GitHub release workflow перед публикацией повторяет тесты, собирает universal-пакет и проверяет SHA-256 всех четырёх assets.
