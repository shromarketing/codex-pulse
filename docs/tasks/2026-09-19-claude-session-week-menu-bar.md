# Claude: сессия и неделя в строке меню

## Цель

Показывать в компактной строке menu bar оба главных окна Claude: сначала остаток текущей сессии, затем общий недельный лимит.

## Результат для пользователя

В режиме «Процент» и «Умный» рядом с официальной иконкой Claude видны два значения: `таймер + остаток сессии` и `календарь + остаток недели`. Полный tooltip и VoiceOver называют оба окна и не смешивают их с Fable.

## Контекст

- `ClaudeBrowserBridge` уже передаёт `session`, `weekly` и модельные недельные окна раздельно.
- Текущая строка меню отображает только `ProviderSnapshot.quota`, то есть один выбранный ограничивающий лимит.
- Сохраняются существующие privacy-границы: только локальные проценты и время сброса, без cookie, чатов и промптов.

## Изменить

- Чистую модель выбора основных окон Claude.
- Нативный renderer menu bar и его tooltip/accessibility label.
- Регрессионные тесты выбора и порядка окон.

## Не трогать

- Pulse Connector, сетевые запросы, хранение квот, floating widget, Fable и публикацию GitHub Release.

## Проверить

- Тест выбора сессии и общей недели, включая отсутствие одного из окон.
- `Scripts/test.sh`, universal build, подпись приложения.
- Живой menu bar: доступные Claude-данные показывают сессию раньше недели; tooltip/VoiceOver содержат полные подписи.
- `git diff --check` и просмотр точного diff.

## Откат

Вернуть menu bar к паре «Codex + один Claude‑процент»; провайдер и сохранённые данные не меняются.
