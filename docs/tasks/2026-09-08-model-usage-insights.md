# Расход Codex по моделям

## Цель

Показать, какие конкретные модели Codex дали расход за выбранный период и в каких проектах они использовались чаще всего — без подмены расхода токенов долей подписочной квоты.

## Результат для пользователя

- Во вкладке «Токены и стоимость → Модели» у каждой модели видны токены, доля локального расхода, оценка стоимости (если она доступна) и проект с наибольшим расходом этой модели.
- В компактном окне Pulse список моделей показывает токены и долю, а также главный проект, когда он определён.
- Если локальный скан ещё не собрал модельные агрегаты, Pulse честно сохраняет пустое состояние и предлагает обновить данные.
- Доля считается только по токенам, для которых локальный источник определил модель. Это не доля лимита ChatGPT Pro.

## Границы

- Не читать тексты чатов, промпты, cookies, ключи и не отправлять агрегаты наружу.
- Не приписывать модели процент лимита, banked reset или стоимость подписки.
- Не менять виджет, сигналы, расписание мониторинга или источники квот.

## Проверка

- Модульный тест покрывает долю модели, неполное покрытие и главный проект.
- Полный `Scripts/test.sh` и release-сборка проходят.
- В установленном приложении проверяется вкладка расхода; при пустом локальном кеше виден честный empty state.

## Откат

Вернуть изменения только в модельных агрегатах и экранах аналитики. Данные аккаунта, квоты и локальная история не удаляются.
