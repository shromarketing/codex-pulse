# Сигналы сброса Claude

## Цель

Добавить в Codex Pulse независимый поток сигналов Claude для неожиданных сбросов и временных расширений общей квоты Claude, с push-уведомлениями и отображением в меню.

## Результат для пользователя

Во вкладке «Сигналы» видны раздельные блоки Codex и Claude. Pulse каждые 30 минут проверяет публичный официальный статус Claude и присылает push только при новом явном сообщении про usage/quota/limit reset или temporary increase. Claude Web, Desktop и Claude Code считаются одной общей квотой; её фактическое состояние по-прежнему подтверждает подключённый Chrome Connector.

## Контекст

- Официальная справка Anthropic подтверждает общую квоту для claude.ai, Claude Desktop и Claude Code.
- Официальный Statuspage доступен публично по `https://status.claude.com/api/v2/incidents.json`, но обычные сбои моделей не являются сигналом сброса.
- Публичные GitHub issues и сторонние трекеры полезны как исследовательский материал, но не считаются достоверным основанием для автоматического push о сбросе.

## Изменить

- Добавить отдельный read-only монитор Claude Statuspage с локальной дедупликацией.
- Принимать только явные сообщения о сбросе/расширении usage-квоты; игнорировать обычные инциденты.
- Отобразить отдельный Claude-блок с источником, московским временем и состоянием подключения квоты.
- Сделать тексты push-уведомлений источнико- и провайдеро-зависимыми.
- Добавить fixture-тесты декодирования и дедупликации.

## Не трогать

- OAuth/cookies/IndexedDB Claude, сторонние приватные API, автоматические действия в Claude Code, Telegram/e-mail интеграции и публикацию.

## Проверить

- `Scripts/test.sh`.
- `Scripts/build-app.sh release native`.
- Новый Claude Statuspage-сигнал уведомляет один раз; обычный service incident не показывается как reset; UI честно сообщает отсутствие анонса.

## Откат

Удалить Claude Reset Signal Monitor и его UI-блок. Codex-сигналы и Claude-квота через Connector останутся без изменений.
