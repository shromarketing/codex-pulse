# Сигналы внеплановых сбросов Codex

## Цель

Добавить в Codex Pulse локальный монитор публичных анонсов о сбросах лимита Codex и нативные macOS-уведомления заранее, не передавая наружу данные аккаунта пользователя.

## Результат для пользователя

Pulse раз в 30 минут проверяет публичную ленту Tibo Sottiaux (`@thsottiaux`, руководитель Codex в OpenAI) через read-only relay. Новый пост с явным анонсом hard или banked reset вызывает одно системное уведомление с ссылкой на оригинал. При первом запуске монитор создаёт тихую базовую точку, чтобы старые посты не пришли как новые уведомления. Codex Spark не показывается среди обычных лимитов.

## Контекст

- Рабочий код: `Sources/CodexPulse/`; источник лимитов — официальный Codex App Server.
- Проверенные внешние контуры: публичный read-only JSON relay ленты `@thsottiaux` и официальный `status.openai.com`.
- Архитектура изученных решений: `thinkingjimmy/codex-reset-watchdog`, `gvm1229/codex-reset-monitor`, `liyoungc/codex-reset-index` — только как примеры формата, классификации и дедупликации. Их скрипты в Pulse не копируются и не запускаются.

## Изменить

- Локальный сервис сигналов: JSON-декодирование, строгая классификация, дедупликация и 30-минутный интервал.
- Нативные уведомления и настройку включения мониторинга.
- Видимый статус последней проверки/сигнала.
- Отображение квот: по умолчанию скрыть отдельный пул Codex Spark, который App Server возвращает параллельно с основным Codex.
- Тесты классификации, тихой первой синхронизации и фильтра Spark.

## Не трогать

- Не добавлять API-ключи X, облако, Telegram, почту, браузерный скрейпинг или авторизацию в сторонних сервисах.
- Не отправлять историю, лимиты, идентификаторы аккаунта, токены или промпты во внешний мониторинг.
- Не менять расчёт основной квоты и не публиковать новую версию приложения.

## Проверить

- `Scripts/test.sh` и `swift build`.
- Тесты с фикстурами для нового/старого/нерелевантного сигнала и отдельного пула Spark.
- Просмотр `git diff`; ручная проверка Settings и dashboard после локальной сборки.

## Откат

Отключить переключатель мониторинга. Код не изменяет лимиты или удалённые данные; возврат к предыдущей версии полностью убирает опрос и уведомления.
