# Понятные и подтверждаемые сигналы сброса

## Цель

Сделать сигналы в Codex Pulse понятными русскоязычному пользователю и не выдавать неопределённый текст поста за точное расписание.

## Результат для пользователя

- Карточка показывает русский краткий смысл анонса вместо сырого английского поста.
- Последние три релевантных анонса доступны как компактная хронология, а оригинал остаётся по ссылке.
- Если из формулировки можно строго вычислить момент (например, «через час» или точное время с часовым поясом), Pulse показывает его в МСК. Для «до конца дня» честно указывает, что точный час и пояс не названы.
- Карточка отделяет ранний публичный анонс Tibo от подтверждения в текущем аккаунте через Codex App Server и показывает число доступных banked resets.
- Ручная проверка не удерживает интерфейс: выполняется с коротким тайм-аутом и не запускает обновление токенов/квот.
- Пользователь может отправить себе тестовое macOS-уведомление из карточки; реальное уведомление по-прежнему отправляется только для нового дедуплицированного анонса.

## Границы

- Не подключать Reddit, форумы, неофициальные трекеры, X API, ключи, облако, Telegram или email.
- Не обещать время сброса, если его нельзя восстановить из поста.
- Не читать и не передавать наружу аккаунтные данные, cookies, токены, промпты или историю чатов.
- Не расходовать и не активировать banked reset.

## Проверка

- Фикстуры проверяют русский смысл, три последних события, вычислимое московское время и честную неопределённость для `end of day`.
- Проверяется тихая baseline-синхронизация, дедупликация и короткий тайм-аут источника.
- Полный `Scripts/test.sh`, release-сборка и ручный UI-smoke установленного приложения.

## Откат

Вернуть только signal-monitor/card/notification view-файлы. Удалённых данных и состояния аккаунта изменения не затрагивают.
