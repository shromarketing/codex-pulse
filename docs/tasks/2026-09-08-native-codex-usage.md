# Нативная аналитика расхода Codex

## Цель

Вернуть в Codex Pulse фактическую локальную разбивку токенов по моделям и рабочим проектам после удаления CodexBar.

## Результат для пользователя

Во вкладке «Токены Codex», в popup и в виджете появляются расход за период, модели и проекты из локальных сессий Codex. Обновление использует кэш неизменённых сессий и не зависит от CodexBar.

## Контекст

- Рабочий код: `Sources/CodexPulse/Services/CostAnalyticsProvider.swift` и модели аналитики.
- Codex App Server продолжает быть официальным источником квот и агрегированной account usage; в локальных `~/.codex/sessions` есть отдельные служебные `token_usage_record`, модель и `cwd`.
- Сканер не читает, не сохраняет и не отображает текст сообщений, промптов, ключи или cookies.

## Изменить

- Добавить локальный сканер служебных JSONL-записей Codex с кэшем по времени модификации и размеру файла; читать только заголовок и хвост каждого журнала.
- Использовать его как основной источник Codex token analytics; CodexBar оставить только явно названным fallback для совместимости.
- Покрыть парсер фикстурами: сумма токенов, разбивка по моделям/проектам, отсечение старого периода и игнорирование текста сообщения.

## Не трогать

- Получение квот, мониторинг сигналов, Claude Connector, удалённые сервисы, публикацию и настройки авторизации.
- Не восстанавливать и не устанавливать CodexBar.

## Проверить

- `Scripts/test.sh`.
- `Scripts/build-app.sh release native`.
- После установки: ручное обновление в «Токены Codex» показывает ненулевые локальные агрегаты; в `git diff` нет содержимого сессий или секретов.

## Откат

Вернуть только изменения сканера и снова использовать пустой/совместимый fallback; квоты Codex App Server останутся независимыми.
