The useful distinction

A percentage only helps when you know which window it belongs to.

01

Window

Codex Weekly, Codex Spark, Claude current session, all models, and model-specific limits stay named and separate.

02

Reset

See when this exact provider window becomes available again instead of inferring it from another plan.

03

Pace

Understand whether the current rate of use is likely to reach the limit before that reset.

The actual app

Menu bar, widget, and dashboard. One local companion.

Use the compact view while you work, then open the full dashboard for provider windows and local aggregate analytics. The task router can suggest a model and effort level before a task starts.

Data boundaries are a feature

Pulse shows what a source returns. It does not make the rest up.

SourcePulse can showPulse does not claim
CodexQuota windows, resets, and local usage aggregates where exposedChat content or prompt history
Claude WebQuota percentages, reset times, and returned model windows such as FableExact token ledger, project attribution, or cost when Claude does not provide it

Read-only, local-first, and no hidden telemetry. Cookies, passwords, API keys, access tokens, account emails, chats, and prompt bodies are not stored by Pulse.

Try the preview carefully

Install from a release — or inspect and build it yourself.

  1. Read the preview caveat.The current DMG and ZIP are universal, but not notarized with Apple Developer ID.
  2. Download and verify.Get the release, compare its SHA-256 against SHA256SUMS, then move the app to Applications.
  3. Keep the safety boundary.Do not disable Gatekeeper or run sudo. If macOS blocks the preview, use its one-app “Open Anyway” flow.
