# Исследование: Claude Desktop и Claude Code в Pulse

Дата: 2026-09-08

## Подтверждённое состояние

- На Mac установлено приложение `/Applications/Claude.app` версии 1.49585.0. В нём присутствует встроенный Claude Code 2.1.260.
- Официальная документация Anthropic подтверждает, что Desktop app позволяет использовать Claude Code без терминала, а локальные Claude Code-сессии по умолчанию хранятся в `~/.claude/projects/` до 30 дней.
- На момент проверки `~/.claude/projects/` не содержит JSONL-сессий. В папке Claude Desktop есть служебная `plan-usage-history.json`, но её поля обфусцированы и не дают подтверждённой семантики токенов/моделей/проектов.
- Web и Desktop/Code при входе в один Claude account используют общую подписку. Их нельзя отображать как два независимых лимита.

## Варианты

1. Прочитать IndexedDB Claude Desktop. Рискованно: там переписки и credentials, структура не является публичным API.
2. Интерпретировать `plan-usage-history.json`. Быстро, но семантика полей не подтверждена — нельзя называть их токенами или квотами.
3. Сканировать документированные локальные Claude Code JSONL-сессии, а также Desktop Code-session folders при появлении там JSONL-метаданных, и оставить Web Connector источником квот. Это даёт честные агрегаты без браузерных данных и заполняется после реального Code-сеанса.

## Решение

Выбран вариант 3. Складываются только числовые usage-поля assistant-записей вместе с моделью, рабочей папкой и датой; текст сообщения игнорируется decoder-ом. Если сессий ещё нет, UI сообщает об ожидании первой Code-сессии, не рисуя нули как данные.

## Ограничение

В текущем состоянии невозможно подтвердить живой токеновый результат до первого Claude Code-сеанса, потому что локальных логов ещё нет. Это не блокирует установку интеграции, но такой результат будет проверен при первом использовании Code.
