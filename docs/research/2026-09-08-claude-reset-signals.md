# Исследование: сигналы о сбросах Claude

Дата проверки: 2026-09-08

## Подтверждённые факты

- Anthropic пишет, что usage claude.ai, Claude Code и Claude Desktop учитывается в одной общей квоте. Поэтому «сброс Claude Code» — это не отдельная корзина, а изменение общей Claude-квоты.
- Claude Code показывает фактическое время ограничения/сброса в интерфейсе usage. Внешний Pulse Connector уже безопасно передаёт из Claude Web только проценты и reset timestamps.
- Публичный `https://status.claude.com/api/v2/incidents.json` работает без авторизации. Он является официальным каналом статуса, но не каждое сообщение о сбое связано с пользовательскими квотами.
- Изученные community monitors (`franksde/quota-monitor`, `haomingkoo/claude-codex-monitor`) напоминают о точном или оценочном обычном reset, но сами не дают авторитетного раннего анонса внепланового сброса. Их практика полезна: локальная дедупликация, отдельная пометка precise/estimated и отсутствие дублей.

## Рассмотренные варианты

1. Мониторить X/Reddit/GitHub сообщения как push-источник. Ранние слухи возможны, но авторство и содержание нельзя стабильно верифицировать; будет шум и ложные тревоги.
2. Читать внутренние API/Keychain/IndexedDB Claude. Может дать квоты, но нарушает private-by-default границы Pulse.
3. Официальный Statuspage + подключённая живая Claude-квота. Statuspage даёт внешнее официальное событие, Connector подтверждает состояние именно аккаунта. Это не обещает анонс перед каждым reset, зато не выдаёт слух за факт.

## Решение

Выбран вариант 3. Claude Statuspage даёт push только когда новый incident/update явно содержит сочетание reset или temporary/increased/extra с usage/quota/limit. Обычные ошибки, доступность моделей и сообщения без квотной семантики игнорируются. В UI у каждого сигнала будет указан источник; актуальный процент и reset time сверяются через Claude Web Connector.

## Ограничение

У Anthropic нет публичного гарантированного канала «внеплановый reset будет тогда-то». Отсутствие Claude-сигнала не означает, что reset не произойдёт; это означает, что официальный источник не публиковал явного анонса. Автоматический push о непроверенных community-постах не включается.
