# Codex Pulse — правила для агентов

## Источник истины

- Рабочий код: `Sources/CodexPulse/`.
- Сборка и упаковка: `Package.swift` и `Scripts/build-app.sh`.
- Продуктовые решения: `docs/PRODUCT.md` и `docs/ARCHITECTURE.md`.
- Визуальный источник: `Resources/design-reference.png`.
- Текущий статус: `00_НАЧАТЬ_ЗДЕСЬ.md`.

## Обязательные границы

- Приложение работает в режиме read-only и не запускает рабочие задачи или модели без явного действия пользователя.
- Не читать историю чатов и не сохранять тексты промптов, cookies, ключи и токены. Текст, введённый в AI-маршрутизатор, можно отправить в эфемерный Codex-анализ только после явного нажатия пользователя; Pulse его не сохраняет.
- Не добавлять скрытую телеметрию. Любая будущая аналитика должна быть локальной либо явно включаемой.
- Не публиковать репозиторий и релиз без отдельной команды пользователя.
- Для Codex использовать официальный App Server. CodexBar CLI допустим только как явно обозначенный совместимый fallback.
- Для Claude не копировать приватные credentials. Использовать подключённый локальный источник либо показывать состояние подключения.

## Проверка перед передачей

- `swift test` или `swift build` проходят.
- `Scripts/build-app.sh` создаёт запускаемый `.app`.
- Проверены dashboard, menu bar, floating widget, RU/EN и три темы.
- `design-qa.md` содержит `final result: passed` либо честно фиксирует блокер.
