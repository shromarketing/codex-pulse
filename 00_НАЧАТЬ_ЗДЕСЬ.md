# Codex Pulse

## Что это

Нативное macOS-приложение для контроля лимитов AI-сервисов и выбора разумного маршрута новой задачи. Первая версия поддерживает Codex и Claude, строку меню, постоянно видимый виджет, русский/английский интерфейс и светлую/тёмную/системную тему.

## Статус

- Статус: локальный MVP собран и проверен, к публичной beta ещё не готов.
- Последняя проверка: 2026-08-10.
- Проверено: universal arm64+x86_64 `.app`, ad-hoc подпись, живой Codex App Server, RU/EN, light/dark, task router, floating widget.
- Ближайший шаг: подключить Claude-сессию для smoke test, затем onboarding, notarization и публичный beta-релиз.

## Источники истины

- Код и сборка: текущая папка, `Sources/CodexPulse/`, `Package.swift`, `Scripts/build-app.sh`.
- Codex-интеграция: официальная документация Codex App Server — `account/rateLimits/read` и `account/usage/read`.
- Claude-интеграция: provider adapter с безопасным локальным fallback; живую авторизацию проверять на подключённом аккаунте.
- Визуальный источник: `Resources/design-reference.png`.
- Не считать актуальными без проверки: концептуальные изображения и данные-заглушки в старых макетах.

## Навигация

- `Sources/CodexPulse` — нативное приложение.
- `Resources` — визуальный источник и иконка.
- `Scripts` — сборка `.app`.
- `docs` — продукт, архитектура, приватность и roadmap.

## Ограничения

- Не публиковать в GitHub и не создавать релиз без отдельного подтверждения.
- Не хранить ключи, cookies, токены, email аккаунтов и тексты задач.
- Не заявлять поддержку Claude как проверенную на конкретном аккаунте, пока он не подключён и не пройдён живой smoke test.
